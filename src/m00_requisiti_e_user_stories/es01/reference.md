# Esercizio 01: La Formula Base della User Story (Soluzione di Riferimento)

## Task A — Correzione dell'Anti-Pattern Tecnico

**Come** Cliente dello shop online  
**voglio** salvare i miei articoli preferiti in una lista dedicata  
**per** poterli ritrovare facilmente e acquistarli in un secondo momento  

---

## Task B — Dalla Richiesta Informale alla User Story

**Come** Lettore di webcomic  
**voglio** memorizzare un segnalibro sull'ultima tavola visualizzata  
**per** poter riprendere la lettura dallo stesso punto anche cambiando dispositivo senza perdere il segno
